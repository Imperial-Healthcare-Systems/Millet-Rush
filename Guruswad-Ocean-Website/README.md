# Guruswad Ocean · MilletRush — Ultra-Premium Website

Built from the *Website Blueprint v1.0* by **Imperial Tech Innovations**.

## What's in this package

| Folder | What it is | Use it to |
|---|---|---|
| `wordpress-theme/guruswad-ocean.zip` | The production **WordPress + WooCommerce theme** (PHP, CSS, JS, fonts, translations) | Upload in WordPress → Appearance → Themes → Add New → Upload |
| `wordpress-theme/guruswad-ocean/` | The same theme as source files | Read or edit the code |
| `static-preview/` | Pages rendered from the real theme templates | Open `static-preview/index.html` in a browser to review the design and motion before installing |

## Preview pages
`index.html` (Home) · `mr.html` (Home in Marathi) · `about-us.html` · `manufacturing.html` · `import-export.html` (with 4-step RFQ) · `farmers-fpo-network.html` · `investment-partnership.html` · `contact-us.html` (Enquiry Hub) · `brands.html` · `brands-milletrush.html` · `news.html` · `404.html`

The preview has no server, so forms, cart and search don't submit, and product packs show styled placeholders until real photos are added in WooCommerce. For the smoothest preview, serve the folder (e.g. `npx serve static-preview`) instead of double-clicking.
